# 喵喵大总结

**喵，让故事继续，让记忆留下。**

meow 系列的 SillyTavern 长聊天记忆插件。聊天变长时，把已经发生的剧情整理进世界书，再隐藏旧消息，保留最近原文继续对话。原始消息仍在聊天档里，需要时可以恢复。

作者：NUE-喵喵电波 · 当前版本：1.2.18

## 能做什么

- **自动记剧情**：达到 token 阈值后自动总结，也可以手动立即总结。
- **选择记忆方式**：追加每次新增剧情，或把旧总结与新剧情合并整理。
- **自己写模板**：传统详述、结构记忆两套风格，各有新增与合并模板，四份独立保存。
- **单独选总结模型**：使用酒馆主 API，或配置独立的 OpenAI 兼容副 API。
- **按聊天档保存**：不同角色和聊天档分别管理总结，可查看历史、复制、导出和撤销。
- **随时看进度**：支持流式接收和中断草稿；悬浮猫咪入口可拖动，靠边后精简为 token 标签。

## 安装

1. 在酒馆打开 **扩展 → 安装扩展**。
2. 粘贴下面的仓库地址，完成安装后刷新页面：

   ```text
   https://github.com/AYUUKI-K/Meow-Large-Summary
   ```

3. 在扩展列表展开 **喵喵大总结**，或点击悬浮入口打开面板。

旧地址 `Mewo-Large-Summary` 仍由 GitHub 重定向。已经安装的用户继续在原插件中更新即可，无需卸载、改安装目录或重复安装；设置、世界书和总结记录保持原样。

已有用户可在插件里点击“检查更新”；更新完成后会自动刷新。

## 快速上手

1. 打开一个角色的聊天档，确认插件顶部的 **启用** 开关已打开。
2. 到 **设置** 选择自动总结、阈值、保留消息条数和总结模式，修改后点击 **保存设置**。
3. 按需编辑 **提示词**，点击 **保存并使用此模板**；只想存下来以后再用，就点 **仅保存模板**。
4. 继续聊天等待自动触发，或在 **概览** 点击 **立即总结并隐藏旧消息**。结果和历史可以在 **记录** 中查看。

第一次总结会自动创建并全局启用世界书，无需提前手动建书喵。

| 默认项目 | 设置 |
| --- | --- |
| 自动总结阈值 | 60000 token |
| 保留最近原文 | 20 条消息，一问一答通常算 2 条 |
| 世界书名称 | 喵喵大总结世界书 |
| 总结连接 | 酒馆当前主 API |

## 两种总结模式怎么选

| 模式 | 适合的用法 |
| --- | --- |
| 多次大总结 | 总结上次以来新增的剧情，追加到当前聊天档的总结条目里 |
| 合并大总结 | 将之前的总结与新增剧情重新整理成一份完整记忆 |

概览里的 **仅合并已有总结** 只整理现有总结，不带当前聊天原文，也不改变消息的隐藏状态。

## 想用单独的总结 API？

在 **设置 → API 与模型** 选择副 API，填写基础 URL 和 Key，从拉取的模型列表中选择模型，或手动填写模型 ID，然后保存设置。

- 副 API 只用于总结，支持 OpenAI 兼容接口。
- 采样使用副接口自身默认值，输出上限为 **65536 token**，不继承主 API 的采样参数、停止词和随机种子。
- 上下文仍由酒馆组装，保留发送时的提示词处理；使用时需保持酒馆主连接可用。

## 总结之后会怎样？

总结生成后，插件会保存世界书、读回确认并检查注入，再隐藏一次旧消息。**隐藏仅执行一次**，之后可以自由使用酒馆的 `/hide` 和 `/unhide` 调整。

- 最近原文也会参与总结；“保留 20 条”决定保存后隐藏到哪里。
- 生成、保存或验证失败时，会显示错误，不会直接隐藏原文。
- 总结后仍超过阈值，会提示并暂停连续自动总结，等待你调整。
- 自动总结目前针对角色卡的单人聊天；群聊不触发。

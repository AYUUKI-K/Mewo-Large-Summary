# 喵喵大总结

一个第三方 SillyTavern 前端扩展：使用当前主 API 在后台生成大总结，将每轮结果保存为一个世界书条目，并在成功保存后隐藏已总结的旧楼层。

## 当前实现

- 默认在 SillyTavern 下一次普通生成的实际上下文达到 60000 token 后排队总结。
- 每次超过阈值只触发一轮；隐藏楼层使上下文低于阈值后，下一次越过阈值才会再次触发，避免大总结自身很长时每轮重复总结。
- 默认保留最新 20 个聊天楼层；阈值、保留数量、插入深度、世界书名和提示词均可修改。
- 默认使用用户提供的 ELLA 提示词，并通过 SillyTavern 的扩展宏替换处理提示词。
- 总结调用当前主 API 的后台 `generateQuietPrompt`，不会在聊天记录里新增一条可见的 AI 楼层。
- 每个聊天存档拥有独立目录分支，每次总结新增一条世界书记录。只有当前存档的最新总结蓝灯注入，旧轮次保留为灰灯记录，避免重复注入造成上下文持续膨胀。
- 总结返回非空内容并成功保存世界书后，才执行 `/hide 0-楼层号`。聊天记录不会被删除，最近设置数量的楼层不会隐藏。
- 插件内目录按角色卡、聊天存档、总结轮次展示，支持查看和删除总结。

## 安装

将此目录作为一个 GitHub 仓库的根目录提交。然后在 SillyTavern 的“扩展”页面使用“安装扩展”粘贴该仓库 URL。扩展后续版本通过 SillyTavern 页面提示检查，用户自行选择更新。

当前工作区尚未配置 GitHub 仓库地址；发布仓库后，将仓库 URL 提供给使用者即可安装。本项目没有设置自动更新。

## 使用

1. 在扩展设置中确认大总结世界书名称，点击“创建/启用世界书”。已有同名世界书会继续使用，不会覆盖其中的其他条目。
2. 检查 60000 token 阈值、保留楼层数和提示词；需要时可在目录中查看或删除各轮总结。
3. 默认已开启“达到阈值后自动总结”，可随时关闭。也可以点击“立即大总结”手动运行，即使自动触发已关闭也可使用。

总结范围由提示词及 SillyTavern 当前生成上下文决定。扩展以 `generate_interceptor` 给出的实际上下文 token 数作为阈值依据，因此条件注入宏或世界书中未实际加入请求的文本不会被当作已发送 token。

## 边界

- 自动触发针对角色卡的单人聊天；群聊不触发。
- 自动触发检查普通生成和会话续写；重试、再生成、滑动和后台静默生成不会触发总结。
- 如果主模型的最大上下文小于阈值，触发条件无法达到，可调低阈值。
- 当前项目是本地源文件，还没有远程 GitHub 仓库地址。

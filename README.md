# 喵喵大总结

版本：0.1.3 | by NUE-喵喵电波

一个第三方 SillyTavern 前端扩展：使用当前主 API 在后台生成大总结，将每轮结果保存为一个世界书条目，并在成功保存后隐藏已总结的旧楼层。

## 当前实现

- 每次普通 AI 回复结束后，重新组装包含该回复的完整提示词并计算 token；达到默认 60000 阈值时立即开始后台大总结，无需用户再次发送。
- 每次超过阈值只触发一轮；隐藏楼层使上下文低于阈值后，下一次越过阈值才会再次触发，避免大总结自身很长时每轮重复总结。
- 默认保留最新 20 个聊天楼层；阈值、保留数量、插入深度、世界书名和提示词均可修改。
- 默认使用用户提供的 ELLA 提示词，并通过 SillyTavern 的扩展宏替换处理提示词。
- 总结复用 API 连接面板里当前主 API 的连接、模型和预设，通过酒馆的主请求接口在后台调用，不需要额外配置 API，也不会新增可见聊天楼层。
- 自定义大总结提示词放在完整提示词的最后，位于预设的所有尾部内容之后；聊天补全请求中为最后一条 user 指令。
- 回复结束后的 token 检查、后台生成、世界书保存及隐藏楼层期间暂停发送；可以保留输入框中的草稿，完成后继续对话。
- 每个聊天存档拥有独立目录分支，每次总结新增一条世界书记录。只有当前存档的最新总结蓝灯注入，旧轮次保留为灰灯记录，避免重复注入造成上下文持续膨胀。
- 总结返回非空内容并成功保存世界书后，才执行 `/hide 0-楼层号`。聊天记录不会被删除，最近设置数量的楼层不会隐藏。
- 插件内目录按角色卡、聊天存档、总结轮次展示，支持查看和删除总结。

## 安装

仓库地址：<https://github.com/AYUUKI-K/Mewo-Large-Summary>。在 SillyTavern 的“扩展”页面使用“安装扩展”并粘贴该仓库 URL。扩展后续版本可在 SillyTavern 页面检查，由用户选择是否更新。

## 使用

1. 在扩展设置中确认大总结世界书名称，点击“创建并启用世界书”。世界书会加入酒馆全局世界书列表并启用；已有同名世界书会继续使用，不会覆盖其中的其他条目。
2. 检查 60000 token 阈值、保留楼层数和提示词；需要时可在目录中查看或删除各轮总结。
3. 默认已开启“达到阈值后自动总结”，可随时关闭。也可以点击“立即大总结”手动运行，即使自动触发已关闭也可使用。

总结范围由提示词及 SillyTavern 当前生成上下文决定。阈值根据回复结束后酒馆组装的最终提示词计算，使用酒馆当前模型的 tokenizer。自定义聊天补全的提示词后处理也在计数前执行，不使用模型最大上下文容量作为 token 数。插件内会显示最近一次检查结果。

例如：本轮发送前为 59000 token，AI 回复后组装为 61000 token，则此时自动总结；保存并隐藏前文后重新计数，低于阈值后恢复下一次自动触发。版本和署名位于展开区域，折叠时隐藏。

如果 API 或保存失败，会显示错误并解除发送锁；API 无正文或世界书未读回确认时不隐藏楼层。

## 边界

- 自动触发针对角色卡的单人聊天；群聊不触发。
- 自动触发检查普通生成和会话续写；重试、再生成、滑动和后台静默生成不会触发总结。
- 如果主模型的最大上下文小于阈值，触发条件无法达到，可调低阈值。
